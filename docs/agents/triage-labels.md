# Triage labels

Komodash uses the **canonical** Matt-Pocock triage vocabulary directly — no aliases. The mapping is 1:1.

## Category roles (exactly one per issue)

- `bug` — something is broken
- `enhancement` — new feature or improvement

## State roles (exactly one per issue)

- `needs-triage` — maintainer evaluation pending
- `needs-info` — awaiting reporter clarification
- `ready-for-agent` — fully specified, delegable to automation
- `ready-for-human` — requires human implementation
- `wontfix` — will not be addressed

## Transitions

`needs-triage` → one of `needs-info` | `ready-for-agent` | `ready-for-human` | `wontfix`.
`needs-info` loops back to `needs-triage` once the reporter responds.

## Rules

- Every triaged issue carries **exactly one** category label and **exactly one** state label.
- All triage comments must begin with: `> *This was generated by AI during triage.*`
